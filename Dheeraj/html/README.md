## How to run it

You need a local web server — browsers block local file access by default.

### Option A — Python (no install needed)

```bash
cd /path/to/this/folder
python -m http.server 8080
```

Then open **http://localhost:8080/SAFE%20Engine.dc.html** in Chrome or Edge.

### Option B — VS Code Live Server

Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension, right-click `SAFE Engine.dc.html` → **Open with Live Server**.

---

## Requirements

- A modern browser (Chrome or Edge recommended)
- Internet connection on first load (Google Fonts + React are loaded from CDN)
- Python 3 **or** VS Code Live Server to serve locally
