01 — Overview

Intro to SAFE

  • Detects sensor failures, outliers, and drift in low-cost air quality sensor data
  • Filters impossible readings using strict hard bounds
  • Flags unusual readings with a rolling z-score detection algorithm
  • Generates CSV summaries and plots for visual analysis
